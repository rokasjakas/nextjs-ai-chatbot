Slack ikonos boto žinutėms

Material Symbols (Google) · Outlined, Fill · Apache 2.0 licencija (tekstas).

  1. Slack'e: kairėje viršuje darbo vietos pavadinimas → Tools & settings → Customize workspace → Emoji → Add Custom Emoji.
  2. Įkelk kiekvieną paveikslėlį ir pavadink tiksliai taip, kaip parašyta (pvz. ms-warning).
  3. Vieną kartą: api.slack.com/apps → jūsų programėlė → OAuth & Permissions → Bot Token Scopes → pridėk emoji:read → Reinstall to Workspace (botas mato, kurios ikonos įkeltos).
  4. Botas pats pastebi įkeltas ikonas (per ~10 min.) ir pradeda jas naudoti žinutėse ir mygtukuose. Kol kurios nors nėra – rodomas įprastas emoji.
